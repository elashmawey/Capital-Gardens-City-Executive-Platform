# 🏛️ المنصة التنفيذية الرقمية لمعاون رئيس جهاز تنمية مدينة حدائق العاصمة
### Capital Gardens City Authority - Executive Assistant Operations Platform
> **جمهورية مصر العربية — وزارة الإسكان والمرافق والمجتمعات العمرانية — هيئة المجتمعات العمرانية الجديدة (NUCA)**

---

## 🌟 نظرة عامة على النظام (Overview)

منصة رقمية متكاملة ومستقلة تماماً، مصممة خصيصاً لتيسير وإحكام مهام **معاون رئيس جهاز تنمية مدينة حدائق العاصمة**، مع ربطها التلقائي بالقواعد واللوائح التنفيذية لهيئة المجتمعات العمرانية الجديدة، وقانون تنظيم التعاقدات الحكومية رقم 182 لسنة 2018، وقانون البناء الموحد رقم 119 لسنة 2008.

**النظام مستقل بنسبة 100% ولا يتطلب أي مفاتيح خارجية أو اشتراكات (بدون Gemini API):**
- محرر وصائغ مذكرات رسمي مدمج بالقوالب والترويسات الحكومية المصرية.
- محرك تقييم وحسابات هندسية فورية للجولات الميدانية ونسب التأخير.
- موسوعة رقمية منضبطة بالسند القانوني واللائحي لقرارات الإزالة وسحب الأعمال.
- يبدأ ببيانات نظيفة تماماً (Zero Default Mock Data) مع إمكانية التصدير والاستيراد الفوري.

## 🚀 الميزات والأقسام الرئيسية (Core Modules)

1. **📊 لوحة القيادة التنفيذية (Executive KPI Dashboard):**
   - مؤشرات الأداء الحية (المشروعات الجارية، الزيارات الميدانية المنفذة، اللجان المنعقدة، ونسب إنجاز الشكاوى).
   - سجل التكليفات المباشرة من السيد رئيس الجهاز، مع إمكانية تعديل نسبة الإنجاز وحذف أو إنجاز التكليف فورياً.
   - تنبيهات المشروعات المتأخرة عن البرنامج الزمني واللجان المجدولة اليوم.

2. **📋 إدارة المرور والجولات الميدانية (Inspection Manager):**
   - تسجيل الزيارات الميدانية اليومية مع قائمة تحقق هندسية فورية (Checklist) لجودة الخرسانات، التشطيبات، السلامة والصحة المهنية، ونظافة الموقع.
   - خانة حرة لإدخال اسم الموقع يدويًا في حال عدم وجوده بقائمة المشروعات.
   - تقييم هندسي فوري وحساب فجوة التأخير والتوصيات الإدارية المقترحة للموقع.
   - طباعة استمارة مرور ميداني رسمية فورية بتوقيع المعاون والاستشاري والمقاول.

3. **🏗️ رصد المشروعات والشركات المنفذة (Projects Tracker):**
   - متابعة المشروعات القومية (سكن لكل المصريين، الإسكان الأخضر، المرافق السيادية، الطرق وأعمال اللاندسكيب).
   - مقارنة بصرية حية لنسب التنفيذ المخططة بالفعالية، مع توليد فوري لمذكرات إنذار لسحب الأعمال في حال التأخر عن البرنامج الزمني.

4. **🤝 لجان الاستلام الابتدائي والنهائي (Handover Committees):**
   - جدولة وتوثيق لجان الاستلام الهندسي للمباني والشبكات ومحطات الروافع.
   - قائمة فحص مطابقة المواصفات مع خانات الملاحظات المعلقة.
   - طباعة محضر استلام رسمي معتمد يتضمن توقيعات أعضاء اللجنة الخمسة (رئيس اللجنة، المعاون، ممثل الإدارة الهندسية، ممثل إدارة التشغيل، ومندوب الشركة المنفذة).

5. **🚨 مكتب الشكاوى ومخالفات الإشغالات (Complaints & Enforcement):**
   - رصد شكاوى سكان المدينة ومتابعة حلها مع الإدارات المعنية.
   - سجل مخالفات البناء وتغيير النشاط مع التنسيق مع **شرطة التعمير** لقرارات الإيقاف والإزالة الفورية ومصادرة المعدات.

6. **✍️ محرر وصائغ المذكرات الرسمية المعتمد (Official Memo Drafter):**
   - صياغة مذكرات عرض، خطابات إنذار مقاولين، تقارير فنية، ومخاطبات وزارية بأسلوب ديواني رفيع مطابق لمعايير هيئة المجتمعات العمرانية الجديدة.
   - طباعة رسمية فورية بترويسة الجمهورية والوزارة والهيئة وخاتم مكتب معاون رئيس الجهاز بدون أي اتصال خارجي.
   - أرشيف داخلي لحفظ واسترجاع المذكرات السابقة.

7. **💼 الحقيبة التنفيذية واللوائح (Executive Toolkit):**
   - حاسبة غرامات التأخير والتعويضات طبقاً لقانون تنظيم التعاقدات الحكومية رقم 182 لسنة 2018 (سقف 10% للأشغال العامة و 3% للتوريدات مع توضيح موقف مصادرة خطاب الضمان النهائي).
   - دليل القواعد واللوائح التنفيذية للبحث الفوري في نصوص قانون البناء 119 لسنة 2008 وقانون 182 لسنة 2018 واللائحة العقارية.
   - تصدير كامل البيانات إلى جداول Excel / CSV بترميز `UTF-8 with BOM` السليم للغة العربية.

8. **🗺️ دليل قطاعات وطوارئ المدينة (City Sectors & Dispatch):**
   - دليل قطاعات مدينة حدائق العاصمة (شرق المدينة، المحور المركزي، سكن لكل المصريين الأخضر، منطقة الخدمات المركزية).
   - أرقام طوارئ المدينة السريعة (غرفة طوارئ مياه الشرب، طوارئ الكهرباء، شرطة التعمير، الإسعاف، جهاز المدينة).

9. **📄 التقرير التنفيذي اليومي المجمع (Daily Executive Brief):**
   - إعداد وطباعة تقرير شامل بضغطة زر يجمع كل مستجدات اليوم للعرض المباشر على السيد المهندس رئيس الجهاز.

10. **⚙️ إدارة وحفظ البيانات محلياً (Data Backup & Privacy):**
    - تصدير نسخة احتياطية كاملة بصيغة JSON وحفظها على جهازك.
    - استيراد النسخة الاحتياطية واستعادتها في أي وقت دون الحاجة لخوادم خارجية.
    - تصفير البيانات وإعادة التهيئة النظيفة بنقرة واحدة.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS, Vite.
- **Icons & UI:** Lucide React, Motion.
- **Backend / Server:** Express.js, TypeScript.
- **Deployment Compatibility:** Vercel (Static + Serverless) + GitHub + Node.js.
- **Privacy & Independence:** 100% автономный (بدون أي API خارجي مدفوع أو متطلب لمفاتيح).

## 📦 خطوات الرفع على جيت هب (Push to GitHub)

افتح موجه الأوامر (Terminal) في مجلد المشروع ونفّذ الخطوات التالية بالترتيب:

```bash
# 1. تهيئة مستودع Git محلي
git init

# 2. إضافة جميع ملفات المشروع
git add .

# 3. حفظ أول Commit
git commit -m "feat: Initial release of Capital Gardens City Executive Assistant Platform"

# 4. تعيين الفرع الأساسي main
git branch -M main

# 5. ربط المستودع بمستودعك الجديد على GitHub (استبدل YOUR_USERNAME و YOUR_REPO)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# 6. رفع الملفات إلى GitHub
git push -u origin main
```

## ⚡ خطوات النشر على فيرسل (Deploy to Vercel)

المشروع جاهز للنشر المباشر بنقرة واحدة على Vercel **بدون الحاجة لأي إعداد للمتغيرات البيئية أو مفاتيح API**:

1. ادخل على [Vercel.com](https://vercel.com).
2. انقر على **"Add New Project"** ثم اختر **"Import Git Repository"**.
3. اختر مستودع المشروع الذي قمت برفعه على GitHub.
4. الإعدادات الافتراضية المكتشفة تلقائياً:
   - **Framework Preset:** `Vite`
   - **Root Directory:** `./`
   - **Build Command:** `vite build`
   - **Output Directory:** `dist`
5. اضغط مباشرة على **Deploy**!
   - لا تحتاج إلى إضافة أي Environment Variables، وسيعمل الموقع بالكامل وبسرعة فائقة.
